# 幻蓝想要和你表白

一场视觉小说与战机小游戏相结合的互动体验。直播结束后，幻蓝为主人打开了一条私人频道。

[点击在线试玩](https://wiswof.github.io/huanlan-confession/)

## 本地运行

无需安装依赖，运行：

```sh
python3 -m http.server 8765
```

然后在浏览器打开 `http://127.0.0.1:8765/`。

## 功能

- 无需输入昵称，全程统一称呼“主人”
- 星海护航：自动射击、连击得分、躲避弹幕与预警激光
- 攻击补给可在本局持续叠加，每个提升单发伤害；火力等级、伤害与弹道即时反馈
- 三段航线：星港近海、霓虹雨城、极光星环；首领分别使用扇形弹幕、预警光束、旋转弹环
- 每次击落首领后，保留装备并修复护盾，通过幻蓝的过场进入新场景；击败最终首领后胜利返航，无倒计时强制结束
- 八类补给：火力、贯穿激光、追踪导弹、僚机、光盾、护盾修复、磁力回收、星爆清屏
- 激光、导弹、僚机和火力持续叠加，敌机耐久、机动、弹速和首领机制随航线增强
- 支持方向键、WASD、鼠标与手机拖动，可暂停、重玩或返回聊天
- 私人陪航：随着战斗进展，幻蓝换用不同姿势与害羞表情，衣装渐进战损，并触发暂停对白；保留不透明衣料遮挡
- 根据当前剧情展示互动选项与心动值，不提前展示流程与结局
- 按回应生成“安心坐标”“同频心动”“双向奔赴”结尾寄语
- 逐字对白、对话回看、可开关的原创程序配乐
- 写给主人、带当次寄语的 PNG 纪念卡
- 手机和桌面适配，支持重新游玩

选择、飞行得分和回忆仅保存在当前页面内存中，刷新后清除；不会提交到服务器。

## GitHub Pages

本仓库可直接用 GitHub Pages 发布。在仓库 **Settings → Pages → Build and deployment** 中，将 Source 设为 **Deploy from a branch**，选择 `main` 分支与 `/ (root)`。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式样式与演出
- `app.js`：剧情、分支、配乐与纪念卡
- `flight.js`：战机模拟、碰撞、弹幕、移动控制与 Canvas 演出
- `assets/`：幻蓝新版插画
- `ASSET_PROMPTS.md`：剧情插画的生成提示词
- `FLIGHT_ART_PROMPTS.md`：战机衣装插画的生成提示词
- `CAMPAIGN_ART_PROMPTS.md`：新增场景、衣装战损及领口调整的提示词

幻蓝是项目所有者的自有 IP。插画依据所有者提供的参考重新设计，未额外附加开源授权。
